# AIML-Based Spatial Transcriptomics

## 📌 Overview
This project focuses on applying Artificial Intelligence and Machine Learning techniques to Spatial Transcriptomics data for analyzing gene expression patterns in cancer tissues.

The system integrates deep learning models such as CNNs and GNNs to differentiate between tumor and normal tissue regions.

## 🧬 Problem Statement
Manual analysis of spatial gene expression is time-consuming and error-prone. This project automates tissue classification using AI-driven spatial and molecular features.

## 🛠️ Technologies Used
- Python
- NumPy, Pandas
- PyTorch / TensorFlow
- Convolutional Neural Networks (CNN)
- Graph Neural Networks (GNN)
- Spatial Transcriptomics Data

## ✨ Key Features
- Spatial gene expression analysis
- CNN-based feature extraction
- GNN-based spatial relationship modeling
- Tumor vs Normal tissue classification
- Visualization of spatial clusters

## ▶️ How to Run
1. Clone the repository
2. Install dependencies using `pip install -r requirements.txt`
3. Run preprocessing scripts
4. Train the model using `train.py`
5. Visualize results from the `results` folder

## 📂 Project Structure
- `data/` – Sample spatial transcriptomics data
- `src/` – Model and preprocessing code
- `notebooks/` – Experiment notebooks
- `results/` – Output visualizations

## 📊 Results
The model successfully distinguishes tumor regions from normal tissues with promising accuracy.
